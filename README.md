This repository contains my practical exercises and projects from Cisco Networking Devices and Initial Configuration. It covers network design, IP addressing, Ethernet switching, network protocols, ARP, DNS, DHCP, and basic network communication. The practical labs include configuring static IP addresses on PCs, setting up switches and routers, creating VLANs, securing network devices, and enabling remote access using SSH. I have also included Packet Tracer files, screenshots, and configuration examples to demonstrate my understanding of basic networking and device management. These projects reflect my progress in building and troubleshooting small networks using Cisco Packet Tracer and the Cisco IOS command line.
